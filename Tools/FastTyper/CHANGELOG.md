# Changelog

## 1.1.0

- Default to Exact text mode for code, using a single paste to avoid typing-triggered auto-indent and bracket completion in web editors.
- Preserve the previous clipboard formats and restore them after pasting, without overwriting a newer copy made by the user.
- Retain randomized timed typing as an optional mode and document how to restart after updates.

## 1.0.0

- Add a native text box, three typing speeds with random per-character delays, and Control + Option + T to start or stop.
- Support Unicode, multiline input, Accessibility setup, Escape cancellation, and cancellation when the active app changes.
